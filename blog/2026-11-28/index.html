你想要快乐，还是不快乐？

读《清醒地活》，有一段话打动了我：“人这一生只有一个选择，你想要快乐，还是不快乐？”

对呀，每时每刻我们都在做选择，如果别人插队了，我正要生气，这时候可以问自己“你要快乐吗？"立马想到没必要跟不相干的人动怒。

再比如工作中被人白嫖了方案，很郁闷的时候问问，”你要快乐吗？“ 答案显而易见，那我继续找新的客户，写新的方案。

如果被熟悉的人利用了，正想骂自己怎么那么蠢的时候，问自己“你要快乐吗？”如果要，那就算了，这次后悔也改变不了什么，下次合作前，把边界说清楚。

不过我们很少做这种选择，因为都有很多限定词 IF 和 BUT。“如果我有钱了，我肯定想要快乐”，“我想要快乐，但是一定先出了这口恶气再说”。

这里说的要快乐，就是无条件地选 YES。

如果把人生看成一段程序，如果选 YES，就走这条路，如果选 NO，常常是回到上一步。

道理很简单，做起来太难了。一切顺利的时候，人很容易快乐。但发生困难的时候，就不那么容易了。很多时候我们都忘了还有选择。但不开心又有什么好处呢？什么都不会改变。

别忘了选择 YES，那个没有 IF 和 BUT 的 YES。
